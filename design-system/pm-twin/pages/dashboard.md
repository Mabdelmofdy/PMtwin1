# Dashboard — Page Overrides

**Pattern:** SaaS workspace overview

## Layout
- Stats grid: 4 columns desktop, 2 tablet, 1 mobile
- Stat cards: flat border, hover border-color shift (no layout-shifting scale)
- Profile completeness bar: 200ms width transition

## Motion
- Stat cards: staggered fade-in-up (60ms interval)
- Panels: sequential fade-in with 80ms offset

## Interaction
- All stat cards are links: `cursor-pointer`, visible hover border
- Banner links: CTA color `#0369A1`
